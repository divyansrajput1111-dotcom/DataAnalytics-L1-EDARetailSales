# Task 1: EDA on Retail Sales Data

# Project Overview
This project performs Exploratory Data Analysis (EDA) on a Retail Sales Dataset using Python.

# Objective
The objective is to analyze retail sales data and identify sales trends, customer behavior, and product category performance.

# Technologies Used
1.Python
2.Pandas
3.NumPy
4.Matplotlib
5.Seaborn
6.VS Code

# Dataset
The project uses a Retail Sales Dataset containing 1,000 records and 9 original columns.

# Analysis Performed
1. Dataset inspection and missing value analysis.
2. Descriptive statistics.
3. Monthly and quarterly sales trends.
4. Customer age group analysis.
5. Gender distribution analysis.
6. Revenue by product category.
7. Correlation heatmap.
8. Average sales by gender.

# Key Findings
The analysis explores sales patterns, customer demographics, and product category revenue to support data-driven business decisions.

# Business Recommendations
1. Offer promotions during low-sales periods.
2. Focus on high-revenue product categories.
3. Create targeted marketing campaigns based on customer demographics.

# Project Files
1.retail_sales_eda.py Python source code.
2.retail_sales_dataset.csv Dataset.
3.Screenshots/ Project output and chart screenshots.
